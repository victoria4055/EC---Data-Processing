# How to run 
*** NEED - Make sure Python3 is installed ***
1. Open GitHub repository link (https://github.com/victoria4055/EC---Data-Processing.git)
2. Click the green (<> Code ) button
3. Choose "Download ZIP"
4. Once downloaded, unzip the folder onto desktop or any preferred location
5. Open terminal on your device
    Mac and Linux : open terminal app
    Windows: search for and open Command Prompt or Windows Terminal
6. Navigate to the project folder (inMemory-DB)
7. After making sure Python 3 is installed, run "python3 db.py"
8. Now you should see the output of all the test cases written in the main function


# Reflection
One improvement for this assignment could be to include more sample test cases to see exactly what the instructions want for the output. Although the directions are generally clear, this would ensure students are implementing the code 100% correctly, exactly how the assignment is asking. The istructions could also be expanded to clarify how errors should be handled and what to do when they appear. Specifically, whether exceptions or custom error messages are wanted. Overall, this was a fun and beneficial assignment that helped reinforce key concepts in data storage and transaction safety.
